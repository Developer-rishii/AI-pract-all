# Experiment 1: Introduction to Prolog language using family tree example.

## Theory:
Prolog stands for programming in logic. Prolog is a declarative language, which means that a program consists of data based on the facts and rules (Logical relationship) rather than computing how to find a solution. 'Query' is a sequence of one or more goals. These goals are entered by the user at the prompt. In Prolog, the program contains a sequence of one or more clauses. The clauses can run over many lines. Using a dot character, a clause can be terminated. This dot character is followed by at least one 'white space' character. The clauses are of two types: facts and rules. Examples of facts are as follows: likes(A, prolog), dexterous(monkey). Rules are specified in the form:

head:- t1, t2, t3,….., tk. Where k>=1

A rule will be read as 'if t1, t2, t3,…., tk are all true, hea9d is true'. :- is known as the clause neck.
